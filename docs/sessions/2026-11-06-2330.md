## Leçons de méthode

- **Relire la convention avant de typer le commit.** J'avais recommandé `refactor` ; `CLAUDE.md` range le code dormant en `chore`, et `WebSocketService` n'a aucun consommateur. Corrigé au cadrage, signalé en point à challenger dans la PR.
- **Un rouge de type est un vrai rouge ici.** Le builder Angular refuse de compiler le spec contre l'ancien port : la suite ne s'exécute plus. Acceptable pour un renommage de contrat ; pour un comportement, on attend un rouge d'assertion.
- **Muter la lecture, pas seulement la valeur.** Figer le token attrape les tests de valeur ; le lire une seule fois attrape ceux de reconnexion. Les deux mutations couvrent les trois tests qui lisent le token.
- **Ne pas solder une dette qu'on ne solde pas.** Le port est aligné pour la lecture, pas pour `refresh()` : l'entrée est réduite et dit qu'aucun test ne prouve la compatibilité avec `AuthService`.
- **Le chemin de `DECISIONS.md` est `docs/decisions/DECISIONS.md`** (premier essai à la racine, raté). `scripts/session-open.ps1` et `session-close.ps1` ne tournent pas hors Windows : handoff écrit à la main, comme les sessions précédentes.
- **Identité de commit** : celle d'Olivier (reprise du dernier commit) avec les lignes `Co-Authored-By` et `Claude-Session`, comme l'exige le workflow ; la configuration git de la session cloud n'est pas la sienne.
