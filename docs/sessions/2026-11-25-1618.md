## Leçons de méthode
- Les statuts se testent mieux par un vrai `game_state_sync` que par une écriture dans `state` : le test suit le chemin de production et ne dépend pas de l'écriture publique que le CDC veut fermer.
- Une mutation « statut figé » attrape plus de tests qu'une mutation locale : à garder pour les `computed` qui lisent un signal.
