## Leçons de méthode

- **Un spy peut cacher le défaut qu'on cherche.** `vi.fn()` attache un gestionnaire aux promesses qu'il retourne : le test « rejet non capturé » est né vert, deux fois (`await Promise.resolve()`, puis attente d'une vraie tâche). Cause trouvée en mutant le `try/catch` du `4002`, dont la détection est connue : le rejet y vient d'une fonction `async`, pas d'un spy. Le test emploie donc une fonction nue. À retenir avant d'écrire tout test « silencieux ».
- **Un test né vert se vérifie avant de se croire.** Prédiction fausse annoncée, exit code et sortie complète relus, mutation de détection faite, plutôt que de commiter un test sans effet.
- **Un fake doit respecter son contrat.** Le `refresh` du `beforeEach` renvoyait `undefined` (`await` l'accepte, `.catch` non) : corrigé dans le fake, pas dans la production.
- **Vert minimal puis refactor listé.** Un seul item (analyse JSON mutualisée), sous vert.
- **Deux rouges pour un CA.** « Appelé » puis « silencieux en cas d'échec » : deux comportements, deux tests.
