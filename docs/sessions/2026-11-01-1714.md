## Leçons de méthode
- **Un test réputé « né vert » échoue parfois au baseline : toujours le lancer avant la mutation.** Deux tests ajoutés ont d'abord échoué ; le second n'était qu'une cascade du premier.
- **`ApplicationRef.whenStable()` sous `vi.useFakeTimers()`** : l'effet de navigation planifie une tâche avec un timer factice ; il faut `await vi.runAllTimersAsync()` avant d'attendre la stabilité, sinon le test expire (5 s).
- **Route transitoire vide (`children: []`)** plutôt que `component: ErrorPage` : évite le double rendu tant que `<app-error-page />` reste dans `app.html`.

## Prochaine cible proposée
