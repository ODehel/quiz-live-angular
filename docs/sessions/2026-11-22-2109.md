- La contradiction avait une racine unique (que vaut un sync absent ou partiel ?) : quatre décisions en cascade, dans l'ordre de leurs dépendances, ont tenu dans une session.
- Le sync partiel est ambigu (aucune partie, ou `PENDING` / `IN_ERROR` / `COMPLETED`) : à garder en tête pour le code de `dispatch()` (CA-30, CA-31).
- Dans `US-ANG-010`, l'exemple de code de `dispatch()` (réinitialisation si statut non actif) n'est pas un CA et n'a pas été touché ; il suppose qu'un sync `COMPLETED` / `IN_ERROR` arrive, ce que le hub n'envoie pas.
