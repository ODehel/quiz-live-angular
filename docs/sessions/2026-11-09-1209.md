## Leçons de méthode
- **Une mutation qui ne produit aucune ligne de résultat n'est pas « tuée », elle a cassé le build** : `@if (true) { … } @else { … }` est refusé par le compilateur Angular, mon script n'a rien affiché pour M1. Rejouée avec `>= 0` (7 rouges). Pour tout script de mutation : exiger la ligne `Tests` avant de conclure.
- **Un `Observable` en erreur sans gestionnaire fait échouer la suite en « Unhandled Errors »** même quand tous les tests passent (`throwError` : RxJS signale l'erreur par `setTimeout`). Le test absorbe `config.onUnhandledError` le temps du test et vérifie qu'il a bien été appelé une fois, puis restaure. À réécrire quand la page traitera l'erreur.
- **Les gardes « né vert » étaient le vrai travail** : trois des neuf tests (liste non vide, un seul thème, avant réponse / échec) sont nés verts, prouvés par mutation (borne, `page` initial). Le cas limite `1 thème` n'existait pas dans mon premier jet et n'était pas tué par `< 2` : ajouté avant les mutations.
- **Le style de la maquette est repris sans rendu observé** (comme à la session précédente) : la règle `margin-left: 0` du bouton recentré vient d'une lecture du CSS (`.btn-primary { margin-left: auto }` dans une colonne centrée), pas d'une capture. Le smoke test doit regarder le centrage.
- **`@($null).Count` vaut 1 en PowerShell** : le script filtre avec `Where-Object { $_ }` avant de compter.
- **Le script de smoke test supprime des données** : `-ClearThemes` est explicite, jamais par défaut ; sans lui le script s'arrête et liste les thèmes présents.
