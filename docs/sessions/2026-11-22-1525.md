## Leçons de méthode
- Le premier rouge est un rouge de compilation (`ng test` type-check ici malgré Vitest) : il a fallu ajouter le seul signal vide pour voir un rouge de comportement. Les rouges « de bonne raison » se vérifient sur le message d'assertion, pas sur l'échec seul.
- Un test sur la référence de la liste (`toBe(before)`) a fait apparaître un retrait qui notifiait pour rien : `toEqual` seul ne l'aurait jamais vu.
- Le mutant sur la garde `username === undefined` n'est tué que par le compilateur : la preuve est `ngc`, pas un test ; noté en dette.
- Le dépôt du hub était lisible dans le bac à sable (`/home/claude/odehel/quiz-live-server`) : le format `{ type, username }` (lignes 117 et 133 de `ws-route.ts`) a été relu, non exécuté.
