## Leçons de méthode

- **Un script de smoke test se valide avant d'être livré.** PowerShell 7.5 se télécharge depuis les releases GitHub dans le bac à sable : le script a tourné de bout en bout contre un faux hub, un Chromium et `ng serve`. Cela a révélé une récursion infinie (`function Git` appelait `& git`, PowerShell ne distingue pas la casse : `OutOfMemoryException`), corrigée en `Invoke-Git`. Non testé : Windows PowerShell 5.1 et Edge ; le smoke test d'Olivier a tourné sans écart.
- **Le script contrôle l'état hors dépôt avant d'agir** (leçon du 2026-11-04) : POST du token avec le mot de passe saisi (masqué) avant toute modification, arrêt expliqué sur 401 (ni `npm run seed`, ni `.env`), mot de passe remplacé dans `environment.development.ts` puis restauré dans un `finally`, `git status` vérifié. Le code du hub n'a pas été lu (fetch refusé par l'allowlist) : le script n'en dépend pas.
- **Hypothèse du handoff précédent invalidée au navigateur.** Le découpage « navigation après l'init, puis Retour à l'accueil » était inutilement lourd : une redirection déclarative couvre les deux (décision #12). Mais « Retour à l'accueil » ne devient pas utile pour autant : la page d'erreur n'apparaît aujourd'hui que si la session n'est pas prête, donc le guard renvoie vers `/error`, vide.
- **Mutant `pathMatch: 'prefix'` survivant** : équivalent, Angular retombe sur la route suivante quand la redirection ne mène nulle part. Ne pas forcer un test artificiel ; le consigner et le verrouiller quand une route enfant le rendra observable.
- **Outils** : `pkill -f "ng serve"` tue son propre shell (la ligne de commande contient le motif, sortie 144) → écrire `[n]g serve`. `gh pr create` échoue en session (GraphQL interdit) → `gh api repos/ODehel/quiz-live-angular/pulls`.
