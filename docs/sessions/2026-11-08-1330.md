## Leçons de méthode
- **Relire la spec du hub avant de cadrer une cible côté client.** Deux sessions de suite, la prémisse d'une cible (US-021) était fausse ou déjà couverte ; la spec du hub tranche en une lecture.
- **Un vert mal placé se voit au rouge.** La garde `isClosed` placée dans le `catch` laissait un second `refresh()` ; le test l'a montré, pas la relecture.
- **Un verdict durci se valide par ses échecs.** `--fail-refresh` passait avec une seule tentative ; six clients jetables ont borné ce qu'il détecte.
