## Leçons de méthode
- **jsdom n'a pas de mise en page** : CDK y juge tous les éléments invisibles et retombe sur le conteneur pour le focus. Le rouge du focus était donc faux tant que le test ne donnait pas de géométrie (`getClientRects` simulé). Lire le code de CDK avant de conclure à un oubli dans le composant a évité d'ajouter un second mécanisme de focus.
- **Mon événement `Échap` était faux, pas le code** : CDK filtre sur `keyCode` (27), jsdom ne le renseigne pas à partir de `key`. Un rouge peut venir du test.
- **Un remplacement de chaîne a touché la mauvaise ligne** (`app.config.ts`, import au lieu des providers) : relire le `git diff` après tout remplacement scripté.
- **Un bouton avec icône dans une page casse tous les tests qui la rendent sans stub** : `app.routes.spec.ts` et `app.config.spec.ts` ont dû être adaptés. Prévoir ce coût pour chaque icône ajoutée à une page.
- **`undefined` n'est pas `null`** : mon premier test d'icône aurait passé avec un élément introuvable. Corrigé (`toBeInstanceOf(SVGElement)`) ; les tests existants du même motif restent en dette.
- **Décision inversée après l'ouverture de la PR** (2026-11-09) : Olivier avait choisi `core/` contre ma recommandation, puis est revenu sur `features/themes/`. Traité en second commit sur la même branche (pas de force push, le squash fusionne les deux), en deux pas sous filet vert : déplacement et renommage purs (242 verts avant et après), puis retrait des options devenues sans objet (2 tests supprimés avec elles). Décision #32 réécrite plutôt qu'ajoutée, car non fusionnée. La dette « générique pour un seul client » a disparu, remplacée par « textes en dur jusqu'au renommage ».
- **Le défaut de largeur venait d'une règle globale de la maquette absente de l'application** : `* { box-sizing: border-box }`. Je l'ai recopiée sans elle et je n'avais pas regardé le rendu, le smoke test d'Olivier l'a trouvé. Un test jsdom a pu le verrouiller (`getComputedStyle().boxSizing`, après une sonde prouvant que jsdom applique les styles du composant), pas la largeur elle-même. Avant de recopier du CSS d'une maquette, chercher ses règles globales (`*`, `body`, variables).
- **Mutations rejouées après un déplacement** : les chemins changent, la permutation titre/libellé n'existe plus. Deux mutants de texte (titre, libellé) la remplacent.
