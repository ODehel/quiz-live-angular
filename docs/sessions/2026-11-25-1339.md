## Leçons de méthode
- Un test qui échoue laisse parfois une erreur non gérée qui fait échouer d'autres tests du même fichier (`guardAgainstUnhandledErrors`) : le nombre de tests rouges d'un mutant n'est pas le nombre de tests qui le détectent vraiment ; lire le premier échec.
- Un mutant qui touche le gabarit et un signal doit modifier les deux fichiers (sinon l'échec de compilation « tue » à tort) : le script de mutation accepte plusieurs éditions.
- Ajouter un appel HTTP à un composant déjà rendu par `app.routes.spec.ts` demande de doubler le service dans ce spec, comme `ThemeService`.
