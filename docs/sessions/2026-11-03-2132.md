## Leçons de méthode
- **`stubIconIn` masque les noms d'icônes non enregistrés** : un test sur le vrai jeu d'icônes (`appConfig.providers`) est le seul endroit où cette erreur peut apparaître. Décision d'Olivier : pas de `it.each` permanent sur l'icône principale (couverte par le contrôle jetable et le smoke test seulement).
- **Un faux hub Node de 15 lignes** (statut 200, 401, ou rien) rend le smoke test hermétique : 4 scénarios sans dépendre du `.env` du hub. Le script est donné dans le chat, hors dépôt.
- **Clone shallow** : la référence de suivi `origin/session/...` n'est pas créée après un `git push`, et le hook de fin de tour signale à tort une branche non poussée. Contournement : `git fetch origin +refs/heads/<branche>:refs/remotes/origin/<branche>`. Vérifier d'abord avec `git ls-remote`.
- **`gh pr create` échoue** (GraphQL indisponible dans la session) : utiliser `gh api repos/ODehel/quiz-live-angular/pulls -X POST` avec `-F body=@fichier`.
