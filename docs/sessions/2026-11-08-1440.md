## Leçons de méthode
- **Le type `Record<variante, configuration>` transforme une variante ajoutée en erreur de compilation** : le « vert » du service (`ErrorService`) n'était pas atteignable sans l'entrée de configuration de la page. Les tests de la page ont donc été écrits avant l'entrée, dans le même rouge de compilation.
- **Un test de page avec doublure d'icône ne prouve pas que l'icône est enregistrée** : le test d'`app.config` (vrai `LucideAngularModule`) a levé l'erreur « icon not provided » avant qu'`AppWindow` soit déclarée.
