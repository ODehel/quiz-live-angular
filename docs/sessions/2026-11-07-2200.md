## Leçons de méthode

- **Un mutant survivant désigne un test manquant.** Le test « autre message » tuait M1 mais pas M2 (`catch` rendant `true`) : seul le cas non JSON le verrouille. Je ne l'ai vu qu'en rejouant les mutations une à une.
- **Vérifier qu'une mutation s'applique.** Ma première forme de M2 (`sed` multi-lignes) n'a probablement rien modifié : elle « survivait » pour une mauvaise raison. Refaite en Python avec une assertion `n != s`, puis `git diff --stat` avant de lancer les tests.
- **La tension anticipée a bien été confirmée sous un rouge** (R2), pas décidée d'avance : le handoff la donnait comme hypothèse.
- **Vert minimal d'abord, protection ensuite.** `JSON.parse` nu au premier vert, `try/catch` seulement sous R2.
