## Leçons de méthode

- **Sonder la faisabilité du test le plus honnête avant de se rabattre sur le moins cher.** Le plan validé était un test de contrat qui lit le SCSS ; une sonde jetable a montré que jsdom résout `--variant-color` depuis les styles compilés du composant. Le test de rendu a remplacé le test de contrat. `console.log` est avalé par le lanceur de tests : la sonde a révélé la valeur par une assertion volontairement fausse (sonde supprimée avant le commit).
- **Une ligne paramétrée née verte reste à muter.** Un `it.each` sur 5 variantes n'a donné qu'un rouge : les 4 autres ont été prouvées par mutation, une par ligne.
- **Chercher la réponse du CDC avant de proposer, puis dire qu'il est muet.** La couleur n'était ni dans CA-25, ni dans la maquette (4 variantes), ni dans la section 14 du design system : le choix est tracé comme décision (#15) et non présenté comme une exigence.
- **Piège `grep` recommis** : options placées après `--` (erreurs traitées comme sorties) lors du relevé de la matrice ; relevé refait avec `--include`/`--exclude` avant `-e`, comptes identiques au précédent. Le piège est dans le handoff précédent : à la prochaine occurrence, écrire le relevé une fois pour toutes dans un script.
- **Smoke test en un seul lancement, vert du premier coup** : pré-contrôles (port 4200 libre, hub joignable), contrôles positifs avant la cible, mesure par protocole de débogage d'Edge pilotée depuis Node (WebSocket global, Node ≥ 22), arrêt des processus en `finally`. - **Démarrer le hub** : pas de README ni de `.env.example` dans `quiz-live-server`. Commandes données à Olivier : `npm start` (port 3000, base `SQLITE_DB_PATH`, défaut `quiz.db`) ; `npm run seed` exige `ADMIN_PASSWORD` et `BUZZER_DEFAULT_PASSWORD` d'au moins 12 caractères (les valeurs par défaut `admin123` et `player123` sont refusées) ; base jetable `smoke.db` (déjà ignorée par git).
