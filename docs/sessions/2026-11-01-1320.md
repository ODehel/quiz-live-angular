## Leçons de méthode
- **`DEBTS.md` et `DECISIONS.md` vont dans le commit de session** (`WORKFLOW.md`, l.90). Je les avais proposés après coup sur #14 : session séparée évitable.
- **Vérifier une hypothèse du récap avant de câbler dessus.** « `provideHttpClient` absent, échec d'injection » était faux : `HttpClient` est `providedIn: 'root'` en Angular 21.2. Une lecture de `node_modules` l'a infirmée en deux minutes.
- **Un test à timers simulés doit installer les faux timers avant l'abonnement.** Premier jet : l'initialiseur s'abonnait dans `beforeEach`, donc avec le vrai délai de 10 s.
- **Le proxy de dev renvoie 500 quand le hub est éteint** : une règle d'erreur par statut HTTP doit en tenir compte (décision #2).
- **« Il me semble » n'est pas une preuve** : l'icône vide est consignée comme observée une fois, autres variantes non vérifiées.
- **Un smoke test headless (Edge + faux hub Node) tourne** pour les cas à réponse rapide ; le cas « hub muet » reste manuel (`-Silent`). `scripts/smoke.ps1` n'est dans aucune PR : à décider.
- **Pas de force push** : une PR peut porter 3 commits, le squash n'en garde qu'un.
